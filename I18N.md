# i18n — Hebrew (and beyond)

Task breakdown for multi-language support. Framework: `i18next` + `react-i18next`.
Languages: `en` (default) + `he` (RTL). Ship task-by-task; each is independently useful.

## Task 1 — Foundation (framework + switcher + RTL/font) ✅ DONE
Plumbing working end-to-end on the NavBar; verified in browser (RTL flip + Hebrew nav).
- [x] Install `i18next`, `react-i18next`, `i18next-browser-languagedetector`.
- [x] `src/i18n.js` — init, fallback `en`, detection (localStorage → navigator).
- [x] `src/locales/en.json` + `src/locales/he.json` (`nav.*` + `common.*`).
- [x] Init i18n in `main.jsx`.
- [x] Direction controller (i18n `languageChanged` → `<html lang>`+`dir`) + no-flash
      inline script in `index.html`.
- [x] Hebrew webfont (Heebo) via Google Fonts; appended to font stacks (per-glyph fallback).
- [x] Language switcher in NavBar (Globe + EN/עב), persists choice.
- [x] NavBar strings translated.

> Known follow-up for Task 4: the side drawer still anchors to physical `right-0` /
> `translate-x-full` — in RTL it should slide from the left (start side).

## Task 2 — Public pages (highest SEO value) ✅ DONE
Translated (en/he) + verified in browser (Hebrew + RTL): Home, Login, Signup,
ForgotPassword, ResetPassword, Studios (+ StudioCard), Pricing, Blog, BlogPost,
StudioProfile. Namespaces: `home`, `auth`, `studios`, `pricing`, `blog`,
`studioProfile`, plus `common`/`footer`. Dates localized via `Intl` where shown.

## Task 3 — App / dashboard pages — ◑ PARTIAL
- [x] **Member dashboard journey**: UserDashboardLayout, Overview, BrowseClasses,
      BrowseStudios, Bookings, ClassCard (namespace `dashboard`). Verified building.
- [ ] **Remaining app screens** (still English — same mechanical pattern):
      UserSettings, StudioSettings, StudioDashboard, Nutrition + NutritionProfileForm,
      WorkoutPlan, Groups, GroupProfile, EventDetail, GroupFeed, Messages,
      AppointmentMatrix, AdminDashboard, AdminBlog.

## Task 4 — RTL layout audit
Sweep directional utilities as pages are done: `ml-/mr-`→`ms-/me-`, `pl-/pr-`→`ps-/pe-`,
`left/right`→`start/end`, `text-left/right`→`text-start/end`; mirror directional icons
(ArrowLeft/ChevronRight) under RTL. Verify each page at both directions.

## Task 5 — Formatting + SEO
- Dates/numbers via `Intl` with the active locale.
- `<html lang>` per language, `hreflang` alternates, translated meta/canonical
  (best after the prerender/SSG sprint so each language is crawlable).

## Notes
- Backend data (studio names, class names, blog posts, user content) stays as authored —
  we translate the **UI chrome**, not user content.
- Adding a third language later = one more `locales/xx.json` + a switcher entry.
